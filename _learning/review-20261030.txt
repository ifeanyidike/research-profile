Findings corrected
------------------
1. Global previous/next links crossed child learning paths. The lesson consumer
   now selects the active path's sequence; browser checks assert C12 -> P01 in

   librosa, SpeechBrain, LiveKit and Kyutai paths; Edinburgh programme 277 was

6. An empty-notebook URL retained an uninterpolated expression. Corrected and
   checked routes for malformed links.
7. Copied SQL resource checks were weaker than browser validation. Both new
   validators now reject non-array/invalid resource checklists; local SQL confirms.

Second review — release 20261030-2
=================================
User requested a fresh review and fixes across teaching, prerequisites, videos,
exercises and UI/UX. Review covered all 84 topic assignments and native checks;
structural validation is not treated as subject-matter or clinical accreditation.

Findings fixed
---------------
1. Every topic in a studio reused a generic pass rubric. Replaced with 252
   observable criteria across 84 distinct rubrics, shown in Learn, Assess and
   the source map. Independent-task answers stay in the revealable solution;
   criteria request an artefact/calculation rather than giving its answer.
2. Important conceptual bridges were too thin: expanded 19 Voice and 19 Child
   lessons, adding 6001 original words across teaching/exercises. Voice now works
   algebra/log rules, derivatives, spread, Fourier coefficients, log-mel/DCT,
   logistic loss, unequal attention, Viterbi updates, CTC path sums, representation
   learning, codecs, retrieval and networks. Child adds developmental domains,
   language components, anatomy, statistics, screening denominators, professional
   reasoning, behavioral definitions and single-case graph interpretation.
3. Broad sources lacked a bounded assignment. All 84 topics now specify study
   focus/sections; MIT calculus comes before optional CMU network material,
   OpenStax anatomy and D2L chapters are directly assigned, and NICE's under-19
   autistic population is explicit. Existing graph/path closure remains valid.
4. Video coverage was sometimes only adjacent context. Added regression and
   neural-codec teaching, a provider-linked audio-LM/Moshi keynote and Youth.gov
   adolescent segments. Removed the C12 sensory workshop as health/swallowing
   instruction. CMU index/YouTube numbering discrepancies are explicitly labelled,
   not resolved by blindly trusting either title. NHS direct-player URLs that
   reject external access now route to exact named clips on the host page.
   An unavailable PyCon async clip was rejected. There are 59 topics with named
   video assignments and 25 explicitly reading-led topics. Many clinical clips
   are family introductions rather than full professional teaching.
5. Caregiver stage -> professional path re-applied a hidden caregiver stage from
   the hash, giving zero topics while the select displayed All stages. Baseline
   reproduced twice. Path changes canonicalise the route and invalid stages are
   cleared. Both switch directions now show the complete 24/28-topic paths.
6. Global search crossed child paths, and professional deep links used the global
   40-topic sequence. Search is path-scoped with a visible scope note. An outside-
   path lesson has an explicit switch action and its own coherent pagination.
   Upcoming reviews also follow the selected path and sort by due date.
7. Index-based resource checklists could misattribute prior completion after a
   new video was inserted/replaced. Resources now carry stable numeric keys;
   unchanged material keeps its old key and new material gets a new one. The
   consumer uses those keys. Backups, database validation and existing progress
   schema stay compatible; no learner data is rewritten.
8. Capstone expectations needed a concrete supplied contract. Added the offline
   V43 initial state, event definitions, seven complete fixtures and uncertain-
   outcome extension. Added wholly fictional age-specific caregiver cases and
   caregiver/professional portfolio templates, with labelled self-review when an
   adult partner is unavailable. No executable model or clinical runner is added.
9. Authoring parser silently overwrote duplicate lesson IDs/fields. It now rejects
   both; duplicate counterexamples were checked offline.
