   and non-shrinking mark fit; narrow headers use ellipsis. Desktop/mobile/theme
   screenshots were inspected, and overflow assertions pass.
4. Several sources returned soft 404s or unrelated content. Corrected ASHA,
   librosa, SpeechBrain, LiveKit and Kyutai paths; Edinburgh programme 277 was
   Management, replaced with verified Speech and Language Processing 290.
5. The async reading assumed JavaScript. Replaced it with Python asyncio and
   added an explicit native bridge; added a trigonometry bridge and statistics
   depth source. Restricted recordings are not advertised as public videos.
6. An empty-notebook URL retained an uninterpolated expression. Corrected and
   checked routes for malformed links.
7. Copied SQL resource checks were weaker than browser validation. Both new
   validators now reject non-array/invalid resource checklists; local SQL confirms.
